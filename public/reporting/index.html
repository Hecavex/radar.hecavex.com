Prepare a reviewed-candidate evidence pack

Load generated Radar JSON files. The page accepts only an active analyst-confirmed assessment, builds a bounded report manifest, and never sends it.

Local-only boundary

  • No network API, report submission, candidate request, cookie, or browser storage is used.
  • Free-form notes and original filenames are excluded to reduce accidental PII disclosure.
  • Optional evidence stays local; only ordinal labels, sizes, media types, and SHA-256 enter the pack.

Advanced maintainer utility — English only

This form requires a completed, active analyst-confirmed assessment. An empty assessments list means there are no usable reviewed candidates; manually adding a candidate is not an assessment. Do not invent a decision to use this form.

  1. Save the public Radar snapshot (radar.json).
  2. Save the sanitized data/review/public-decisions.json from the matching release. Follow the maintainer review workflow.
  3. Open the corresponding permanent Radar signal record and save its “Signal JSON” link: /data/signals/ID-prefix/ID.json, where ID-prefix is the first two characters of the stable signal ID.

These are explicit navigation/download links. Selecting files performs only local validation; the tool never fetches inputs automatically.

Maximum 20 files, 10 MiB per file and 25 MiB combined.
