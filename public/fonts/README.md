# HECAVEX type assets

The production interface at `radar.hecavex.com` self-hosts Latin and Latin Extended subsets. Inter and IBM Plex Mono are sourced from Fontsource 5.3.0; Space Grotesk is the variable Fontsource distribution used by the September 2026 portfolio redesign. All are distributed under the SIL Open Font License 1.1.

- Inter is used for interface and reading text.
- Space Grotesk is used for display headings; the Latin Extended subset includes Lithuanian diacritics.
- IBM Plex Mono is reserved for evidence identifiers, timestamps, URLs and data values. Navigation and descriptive labels use Inter.

The complete license texts are stored beside this file as `INTER-OFL.txt` and `IBM-PLEX-MONO-OFL.txt`, and in `space-grotesk/OFL.txt`.
